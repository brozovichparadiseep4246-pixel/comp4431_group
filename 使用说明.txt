【一、运行环境要求】
  · Windows 10/11
  · Python 3.11 或更高版本（https://www.python.org/downloads/ 下载，
    安装时务必勾选 "Add python.exe to PATH"）
    —— 如果已安装 uv (https://docs.astral.sh/uv/) 则 Python 非必需

【二、启动步骤（共 2 步）】
  1. 解压本压缩包到任意文件夹
  2. 双击 run.bat
     · 首次运行会自动安装依赖（约 3-10 分钟，取决于网速），请耐心等待
     · 之后浏览器会自动打开 http://127.0.0.1:7860
     · 保持黑色命令行窗口开启；关闭窗口即停止服务

【三、使用说明】
  · 在底部输入框输入选课问题（支持中文/英文），回车或点蓝色按钮发送
  · 点击输入框下方的麦克风录音，录完点“🎤 提问”即可语音对话；
    勾选“🔊 语音播报”后机器人会用语音朗读回答
  · 右上角卡通吉祥物会随对话变化表情动作（思考、眨眼、对口型等）
  · 右下角“模型引擎”可切换：
      - 在线大模型（RAG 检索）：需配置任意免费 API Key（见第四节，推荐 Groq）
      - 本地微调（离线）：无需任何 Key 和联网，使用的是本组自行 LoRA 微调的
        Qwen2.5-0.5B 模型（首次切换需自动下载基座模型约 1GB，请耐心等待）

【四、在线大模型 API Key 配置（可选，均为免费方案）】
  不配 Key 不影响演示——直接使用“本地微调（离线）”引擎即可。
  如需使用“在线大模型”引擎，任选一个免费服务（2 分钟注册完成，无需绑卡）：

  ★ 推荐 Groq（开源模型，免费额度充足）
    1. 打开 https://console.groq.com/keys 注册并创建 API Key（gsk_ 开头的一串字符）
    2. 打开项目文件夹（run.bat 所在文件夹），找到 .env.example，
       复制一份并把副本重命名为 .env（全名就是 .env，不是 .env.txt）
    3. 用记事本打开 .env，找到 "方案一" 下面这一行：
         # LLM_API_KEY=gsk_xxxxxxxxxxxxxxxx
       删掉行首的 # ，把 gsk_xxxxxxxxxxxxxxxx 换成你的 Key，保存。
       （LLM_BASE_URL / LLM_MODEL 两行保持注释状态即可，默认值就是 Groq）
    4. 重新双击 run.bat 启动

  其他可选：OpenRouter 免费模型 / Google Gemini 免费额度 / Moonshot Kimi，
  配置方法见 .env.example 内的注释。

【五、常见问题】
  Q: 浏览器没自动打开？
  A: 手动在浏览器地址栏输入 http://127.0.0.1:7860

  Q: 双击 run.bat 一闪而过 / 报错“未找到 Python”？
  A: 未安装 Python 或未勾选 Add to PATH，请按第一节安装后重试。

  Q: 首次使用语音或本地模型时等待很久？
  A: 正常现象——首次使用需从 HuggingFace 下载模型
    （语音识别 75MB / 本地大模型基座约 1GB），下载一次后永久缓存。

  Q: 回答的知识不准确？
  A: data\courses.json 中为演示用课程示例数据，本项目重点展示聊天机器人
    技术实现（RAG / 微调 / 语音 / 虚拟形象）。

  Q: 端口 7860 被占用？
  A: 关闭其他占用程序，或设置环境变量 GRADIO_SERVER_PORT=其他端口 后再运行。
